# Brand direction: editable starting points
- `design-tokens.json` is the **approved** source for colors, typography and product option names.
- `parall-symbol.svg` is a simple **original concept icon** built for this package, not mandatory final logo. Feel free to refine while retaining PARALL identity.
- `parall-wordmark.svg` is a typographic **mockup** showing PARALL / 01 proportions. Syne, Inter or fallback font may render depending on machine; create your own polished implementation in website typography, not a screenshot.
- Product 3D GLB is **not included**. Claude must build/source it using `docs/07_3D_AND_ASSETS.md` and verify usage rights.
